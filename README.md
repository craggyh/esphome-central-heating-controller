This is an esphome configuration I built for completely managing my homes central heating using a solid fuel stove (wood burner) and oil boiler. The code also incorporates NEST thermostats for interactive control over upstairs/downstairs zones and separate hot water control with automation.
The controller is a Kincony A8 board with 8 relay channels and 8 digital inputs for ds18b20 temperature probes along with analog inputs for motorised valves state plus a pressure sensor monitoring overall central heating system pressure. The code can be adapted to work with any relay board to suit your requirements.
